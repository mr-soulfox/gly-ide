# Gamelly - Gly IDE

A playground to code your Lua games directly in the browser!

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`VITE_WEB_RTC_URL` -> Use from .env.sample;

`VITE_ENGINE_VERSION` -> Defined at build from engine;

## Run Locally

Clone the project

```bash
  git clone https://github.com/gamelly/gly-ide
```

Go to the project directory

```bash
  cd gly-ide
```

Install dependencies

```bash
  npm install
```

Run the page

```bash
  npm run dev
```
